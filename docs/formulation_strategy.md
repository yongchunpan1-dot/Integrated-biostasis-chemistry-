# IBC Formulation Strategy

## Core Principle

IBC does not directly combine individual materials.

Instead, formulation discovery proceeds through two stages:

1. Intra-mechanism optimization
2. Inter-mechanism integration

This reflects the assumption that each entropy-control mechanism can independently reduce biological-state drift.

---

## Stage 1: Intra-mechanism Optimization

### Structural Stabilization

Candidate formulations:

- Trehalose
- Trehalose + PEG
- Trehalose + Dextran
- Trehalose + Glycerol
- Dextran + PEG

### Chemical Stabilization

Candidate formulations:

- Trolox
- Trolox + EDTA
- Trolox + Glutathione
- Catalase
- Catalase + Trolox

### Physical Encapsulation

Candidate formulations:

- Silica
- Calcium phosphate
- Silica + Trehalose
- Hydrogel
- Hydrogel + Trehalose

Top formulations from each class advance to Stage 2.

---

## Stage 2: Inter-mechanism Integration

Examples:

### Structural + Chemical

- Trehalose + Trolox
- Trehalose + Trolox + EDTA
- Trehalose + Glutathione

### Structural + Encapsulation

- Silica + Trehalose
- Calcium phosphate + Trehalose
- Hydrogel + Trehalose

### Chemical + Encapsulation

- Silica + Trolox
- Calcium phosphate + Trolox

### Structural + Chemical + Encapsulation

- Silica + Trehalose + Trolox
- Calcium phosphate + Trehalose + Trolox
- Hydrogel + Trehalose + Trolox

---

## Initial Screening Objective

Identify formulations that maximize preservation across:

- Membrane state
- Protein state
- Nucleic-acid state

using a composite Temporal Fidelity Index (TFI).

The first experimental generation should prioritize mechanistically diverse formulations rather than exhaustive combinatorial exploration.
